# Downloads · Portfolio Oscar Brand

Dieses Repository enthält keinen Code, nur die **macOS-Apps** aus dem Portfolio als Release-Downloads.
Zu jeder App gibt es eine Projektseite mit Beschreibung, Bildern und (wo möglich) einer Browser-Version.

**Hinweis:** Die Apps sind nicht signiert. Beim ersten Start im Finder per Rechtsklick → „Öffnen“ starten
(oder unter *Systemeinstellungen → Datenschutz & Sicherheit* freigeben). Debug-Builds sind entsprechend gekennzeichnet.
